# My dotfiles (simple arch+hyprland setup, inspired by omarchy)

Usage:
1. Install arch (archinstall recommended)

1.1 Connect to the internet

2. Clone repo:

```bash
cd
git clone --single-branch --branch custom_os https://github.com/roger-padrell/dotfiles
cd dotfiles
```

3. Setup (install dependencies): `./scripts/setup.sh`

4. Update local config (my dotfile customization): `./scripts/update.sh`

5. Enjoy :)
